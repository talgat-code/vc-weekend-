# BCC Business — помощник по валютным переводам

Интерактивный MVP для кейса BCC Future Talent. Пользователь проходит четыре шага: выбирает валютный договор, готовит заявление, проверяет платёж и получает понятный статус следующего действия.

## Запуск

```bash
npm install
npm run dev
```

Для полного сценария с AI-проверкой запустите FastAPI в отдельном терминале:

```powershell
Copy-Item ai-backend/.env.example ai-backend/.env
# добавьте OPENAI_API_KEY только в ai-backend/.env
npm run api:python
```

При запуске на `0.0.0.0` фронтенд автоматически обращается к API на том же
хосте, порт `8000` (или к адресу из `VITE_API_BASE_URL`). Ключ OpenAI не должен находиться в `.env` Vite и не
попадает в браузер. Если ключ ещё не добавлен, API продолжает работать через
безопасный детерминированный fallback для автономного сценария.

Для production-сборки:

```bash
npm run build
npm run preview
```

## Сквозной сценарий MVP

- Договор можно выбрать из мокового списка или загрузить файл. Файл отправляется только в локальный FastAPI-сервис для извлечения полей; содержимое не попадает в браузерный код.
- Заявление требует номер, дату и подтверждающий документ. Поля можно заполнить вручную или извлечь из загруженного файла.
- В платёжных реквизитах есть контролируемое расхождение суммы: помощник останавливает переход и показывает, что именно нужно сверить.
- Финальный экран показывает пример статуса. Реальной отправки в банк, подписания или обработки данных нет.

Стек: React, Vite, Tailwind CSS, локальные shadcn-стилизованные UI-компоненты и Lucide icons.

## Данные и API

В `data/cases.json` подготовлены три пары синтетических договора и инвойса: корректный кейс, отсутствие IBAN и превышение суммы договора. FastAPI запускается командой `npm run api:python` на `0.0.0.0:8000`; `npm run check` проверяет прежние локальные правила. Экран платежа обращается к `/api/v1` и показывает замечания и счётчики для текущего черновика. Без ключа OpenAI сервис использует детерминированный fallback, а при наличии ключа в `ai-backend/.env` `/analyze` вызывает OpenAI Responses API на сервере.

## Материалы для защиты

Готовые синтетические документы для загрузки, последовательный сценарий живой демонстрации, значения всех 25 полей и структура презентации лежат в [demo-kit](demo-kit/README.md). Никакие файлы из этого набора не являются настоящими платёжными или персональными данными.
В `data/cases.json` находятся синтетические данные для автономного запуска. FastAPI запускается командой `npm run api:python` на `127.0.0.1:8000`; `npm run check` проверяет локальные правила. Экран платежа обращается к `/api/v1`, а контрольная карта «Готовность платежа» показывает, что уже проверено и что сделать дальше. Без ключа OpenAI сервис использует детерминированный fallback, а при наличии ключа в `ai-backend/.env` `/analyze` вызывает OpenAI Responses API на сервере.
