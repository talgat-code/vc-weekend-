# BCC Business — помощник по валютным переводам

Интерактивный MVP-прототип для кейса BCC Future Talent. Пользователь проходит четыре шага: выбирает валютный договор, готовит заявление, проверяет платёж и смотрит демо-статус.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Сценарий прототипа

- Договор можно выбрать из мокового списка или загрузить файл. После выбора файла форма показывает пример извлечённых AI полей; содержимое файла не загружается и не отправляется на сервер.
- Заявление требует номер, дату и подтверждающий документ. Для быстрого прохода предусмотрена кнопка демо-инвойса.
- В платёжных реквизитах намеренно есть одно расхождение: в назначении указано 48 000 USD, а в инвойсе — 48 500 USD. Помощник останавливает переход, пока пользователь не подтвердит исправление.
- Финальный экран показывает пример статуса. Реальной отправки в банк, подписания или обработки данных нет.

Стек: React, Vite, Tailwind CSS, локальные shadcn-стилизованные UI-компоненты и Lucide icons.
