# Интеграция демо-данных и API

Запуск: Node 20+; `npm start`. Сервер слушает `127.0.0.1:3001`. Зависимостей и установки пакетов нет. Проверка: `npm run check`.

Фронт на Vite (`http://localhost:5173`) может вызывать API напрямую. Для другого origin задайте `CORS_ORIGIN`. Ключ Claude хранится только в серверной переменной `ANTHROPIC_API_KEY`; модель задаётся через `ANTHROPIC_MODEL`. Без этих переменных демо полностью работает, а `/api/explain` отдаёт детерминированное объяснение. Никаких реальных документов или ключей в репозиторий не добавлять.

| Метод | Маршрут | Результат |
| --- | --- | --- |
| GET | `/api/health` | Проверка сервера |
| GET | `/api/cases` | Три сценария: `clean`, `missing-iban`, `amount-conflict` |
| GET | `/api/cases/:id` | Синтетический договор, инвойс и результат проверки |
| GET | `/api/fields` | 25 полей формы по порядку |
| POST | `/api/analyze` | `{ "caseId": "clean", "edits": { "amount": 25500 } }` или объект `{contract,invoice,edits}` |
| POST | `/api/explain` | `{ "caseId": "missing-iban" }`; объяснение без изменения данных |

В `analysis.fields` — предложенные значения с правками пользователя; `suggestions` — исходные предложения; `provenance` — источник и пометка о необходимости проверки; `issues` — замечания с `severity` (`blocking`, `warning`, `review`); `status` — `draft-review` или `needs-correction`; `metrics` — счётчики для демо. Числа `proposedCount` и `autoFilledCount` относятся только к демонстрационным полям, не к качеству реального AI. Данные извлекаются из заранее подготовленной структуры, а не из произвольных PDF/DOCX.

Кнопка фронта «Продолжить» может переходить к редактированию черновика при `draft-review`. При `needs-correction` показывайте `issues` и `nextStep`. Не показывайте кнопку реального подписания или отправки. `UNK_REVIEW` — напоминание обратиться к специалисту банка, без автоматического решения о постановке на учёт.

Пример вызова:

```js
const result = await fetch('http://localhost:3001/api/analyze', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ caseId: 'missing-iban', edits: {} })
}).then(response => response.json());
```

Для оценки эффекта сравнивайте с ручным сценарием: время до черновика, долю исправленных полей, замечания до подачи, возвраты на исправление и обращения в поддержку. Текущие счётчики API — демонстрационные, без реальных данных банка.
